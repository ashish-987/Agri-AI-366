# AgriAI 366: Smart Farming Ecosystem

An all-in-one AI ecosystem for modern agriculture across 366 Indian districts.

## 🌟 Key Features
- **Stitch 3D Telemetry Canvas**: Interactive 3D plant & orbital AI telemetry nodes displaying real-time soil moisture, NDVI, NPK, and microclimate data.
- **AI Crop Disease Diagnostic Scanner**: Upload leaf photos for 98.4% accurate pathogen detection, bounding box lesion highlighting, and PDF treatment reports.
- **24/7 AI Voice Agronomist**: Integrated browser Web Speech API for real-time speech input & spoken advisory answers in Hindi, English, and Punjabi.
- **AI Mandi Price Explorer & Best Market Optimizer**: Real-time APMC Mandi price forecasting, transport cost calculation, and buyer directory.
- **P2P Equipment Leasing Hub**: Rent tractors, harvesters, and spraying drones from nearby farmers at hourly rates.
- **Digital Twin Farm Management & Ledger**: Track crop lifecycle stages, NDVI vegetation indices, and farm expenditure ledgers.

## 🚀 Tech Stack
- **Frontend**: React 18, Vite, Three.js, TailwindCSS, Lucide Icons
- **Speech API**: Web Speech API (`speechSynthesis` & `SpeechRecognition`)
- **Graphics**: WebGL GLSL Shader & Three.js 3D Engine

## 🛠️ Local Setup
```bash
npm install
npm run dev
```

Application will run locally at `http://localhost:3000/`.
